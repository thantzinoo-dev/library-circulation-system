CHAPTER 3

IMPLEMENTATION AND DESIGN OF SCHOOL LIBRARY
MANAGEMENT SYSTEM

This paper presents school library management system by using C# programming language in ASP.NET Core framework to manage school library circulation and book catalogues. This system allows admins and users to view the book information and circulation records. In this system, admins only can manage book details, categories, members, borrow and return transactions, and system settings. Admins only can manage users.

3.2 Summary

In this chapter, the user interface design and operational workflows of the School Library Management System were presented. The interface provides accessible and responsive interactions for both public patrons and administrative personnel, ensuring efficient circulation management, inventory tracking, and institutional reporting.
